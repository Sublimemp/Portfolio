# UNT Rides Web Application

## Overview

UNT Rides is a web-based rideshare application that allows University of North Texas students to post and request rides. Ride postings include the destination, starting location, departure time, and price. Students can request to join a ride and are directed to a confirmation page containing the driver's email so they can coordinate the ride and payment.

## Features

* User sign up, log in, and log out
* Ride posting creation
* Ride request functionality
* Ride posting edits
* Account information updates
* Forgot password functionality
* Inappropriate ride flagging
* Admin commands to approve or delete rides
