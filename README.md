## Projects

### UNT Rides Web Application

UNT Rides is a web-based rideshare application designed to support ride request and confirmation workflows. The system demonstrates full-stack development through authentication, routing, and persistent data storage.

Technologies Used:

* JavaScript  
* Node.js  
* Express  
* SQLite  
* HTML / CSS  

Key Features:

* Handles creation and storage of ride requests through a structured SQLite database  
* Supports authenticated user sessions to manage ride activity  
* Processes multiple ride records within a persistent storage system  
* Uses modular Express routing to separate ride, user, and database logic  
* Dynamically renders ride information to users through server-side responses  

Performance-Based Implementation:

* Designed to manage multiple ride requests stored in a relational database  
* Structured to support repeated ride submissions without data conflicts  
* Maintains organized user and ride data through database-backed operations  
* Built with a scalable routing architecture to support future system expansion  
* Supports creation, storage, and retrieval of ride records through structured queries  
* Tested using simulated ride entries to verify database storage and retrieval functionality  

Status: In Progress
